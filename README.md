# TURN ON THE BASS
## Fishing rhythm game with rod controller!

There are three things I really, really like: **fishing, rhythm games, and crazy controllers**. So, if I can merge them into one prototype? That's what I'm doing!

There are two crucial parts of this project: a simple prototype of a fishing minigame and an RPi Pico-based fishing rod controller (custom-made one!).
